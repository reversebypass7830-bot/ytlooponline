## Overview

Ye proxy YouTube videos ke download links provide karta hai aur video files ko directly stream kar sakta hai. Kisi bhi third-party cookies ya authentication ki zaroorat nahi hai.

**Flow:**
```
Client → Proxy API → ytultra API → googlevideo.com → Client
```

---

## API Endpoints

### `GET /api/download`

| Parameter | Required | Description |
|-----------|----------|-------------|
| `url` | ✅ Yes | YouTube video URL |
| `stream` | No | `1` = direct video file download |
| `itag` | No | Specific format itag (used with `stream=1`) |

### `POST /api/download`

Same parameters, but pass `url` in request body as JSON:

```json
{
  "url": "https://www.youtube.com/watch?v=VIDEO_ID"
}
```

### Response Fields

| Field | Type | Description |
|-------|------|-------------|
| `ok` | boolean | Request success status |
| `title` | string | Video title |
| `thumbnail` | string | Thumbnail image URL |
| `duration` | string | Duration in seconds |
| `video[]` | array | Video streams (mp4/webm) |
| `audio[]` | array | Audio-only streams (m4a/weba) |
| `video[].url` | string | Direct download URL |
| `video[].quality` | string | Quality label (144p, 360p, 720p, etc.) |
| `video[].ext` | string | File extension |
| `video[].fileSize` | number | File size in bytes |
| `video[].size` | string | Human-readable file size |

## Stream Mode — Direct Download

Video file directly download karne ke liye `stream=1` add karo.

### Download Video (default 144p)

```
GET /api/download?url=https://www.youtube.com/watch?v=dQw4w9WgXcQ&stream=1
```

### Download Specific Quality

```
GET /api/download?url=https://www.youtube.com/watch?v=dQw4w9WgXcQ&stream=1&itag=136
```

### Download Audio Only

```
GET /api/download?url=https://www.youtube.com/watch?v=dQw4w9WgXcQ&stream=1&itag=140
```

**Response:** Direct file stream with `Content-Disposition: attachment` header.

## Available Formats & ITags

### Video Formats

| itag | Quality | Extension | Typical Size (10min) |
|------|---------|-----------|---------------------|
| 394 | 144p | mp4 | ~5 MB |
| 160 | 144p | mp4 | ~10 MB |
| 133 | 240p | mp4 | ~15 MB |
| 134 | 360p | mp4 | ~25 MB |
| 135 | 480p | mp4 | ~40 MB |
| 136 | 720p | mp4 | ~70 MB |
| 298 | 720p60 | mp4 | ~100 MB |
| 137 | 1080p | mp4 | ~150 MB |
| 299 | 1080p60 | mp4 | ~200 MB |
| 264 | 1440p | mp4 | ~300 MB |
| 308 | 1440p60 | webm | ~350 MB |
| 266 | 2160p | mp4 | ~500 MB |
| 315 | 2160p60 | webm | ~600 MB |
| 18 | 360p | mp4 | ~25 MB (progressive, audio+video) |

### Audio Formats

| itag | Quality | Extension | Typical Size (10min) |
|------|---------|-----------|---------------------|
| 139 | 48kbps | m4a | ~1 MB |
| 140 | 128kbps | m4a | ~2 MB |
| 251 | 160kbps | webm | ~3 MB |

> **Note:** Progressive formats (itag 18) mein video + audio dono hote hain. Adaptive formats (133-315) mein sirf video hota hai — audio alag download karna padega.

```javascript
// 3. Download with fetch + blob (in-page download)
async function downloadAsBlob(youtubeUrl, itag = 160) {
  const url = `https://yt-download-proxy-cqkedn65a-dev-e6b8.vercel.app/api/download?url=${encodeURIComponent(youtubeUrl)}&stream=1&itag=${itag}`;
  const res = await fetch(url);
  const blob = await res.blob();
  
  const a = document.createElement('a');
  a.href = URL.createObjectURL(blob);
  a.download = 'video.mp4';
  a.click();
  URL.revokeObjectURL(a.href);
}

// 4. Download with progress tracking
async function downloadWithProgress(youtubeUrl, itag, onProgress) {
  const url = `https://yt-download-proxy-cqkedn65a-dev-e6b8.vercel.app/api/download?url=${encodeURIComponent(youtubeUrl)}&stream=1&itag=${itag}`;
  const res = await fetch(url);
  const total = parseInt(res.headers.get('content-length') || '0');
  const reader = res.body.getReader();
  
  let received = 0;
  const chunks = [];
  
  while (true) {
    const { done, value } = await reader.read();
    if (done) break;
    chunks.push(value);
    received += value.length;
    if (onProgress && total) onProgress(received / total * 100);
  }
  
  const blob = new Blob(chunks, { type: 'video/mp4' });
  const a = document.createElement('a');
  a.href = URL.createObjectURL(blob);
  a.download = 'video.mp4';
  a.click();
}
```

### Python

```python
import requests

BASE_URL = "https://yt-download-proxy-cqkedn65a-dev-e6b8.vercel.app/api/download"

# 1. Get download links
def get_links(youtube_url):
    res = requests.get(BASE_URL, params={"url": youtube_url})
    data = res.json()
    
    if not data.get("ok"):
        raise Exception(f"Error: {data.get('error')}")
    
    print(f"Title: {data['title']}")
    print(f"Video streams: {len(data['video'])}")
    for v in data['video']:
        print(f"  {v['quality']} [{v['ext']}] - {v.get('size', '?')}")
    
    return data

# 2. Download video file
def download_video(youtube_url, itag=136, filename="video.mp4"):
    url = f"{BASE_URL}?url={youtube_url}&stream=1&itag={itag}"
    res = requests.get(url, stream=True)
    
    with open(filename, 'wb') as f:
        for chunk in res.iter_content(chunk_size=8192):
            f.write(chunk)
    
    print(f"Downloaded: {filename}")

# Usage
data = get_links("https://www.youtube.com/watch?v=dQw4w9WgXcQ")
download_video("https://www.youtube.com/watch?v=dQw4w9WgXcQ", itag=136)
```

## Error Handling

### Error Response Format

```json
{
  "error": "Error message here"
}
```

### Common Errors

| HTTP Code | Error | Solution |
|-----------|-------|----------|
| 400 | `Missing url parameter` | Pass `url` query parameter |
| 400 | `Invalid YouTube URL` | Use valid youtube.com or youtu.be URL |
| 404 | `No stream found` | Check itag value, try without itag |
| 502 | `Upstream error` | ytultra API down, retry later |
| 500 | `Internal error` | Server error, retry |

## Rate Limits & Notes

- **No authentication required** — API is public
- **No rate limit** currently enforced (be reasonable)
- **Vercel Hobby plan** — 100GB bandwidth/month, 10s function timeout for JSON mode
- **Stream timeout** — Vercel has a function execution limit; large files may timeout
- **Googlevideo URLs expire** — URLs from JSON mode have `expire=` parameter, use within ~6 hours
- **Best for:** Short videos, getting download links for client-side download
- **Not ideal for:** Very large files (>500MB) via stream mode (timeout risk)

### Recommendations

1. **For browser apps:** Use JSON mode to get links, then download client-side
2. **For scripts/tools:** Use stream mode for small files, JSON mode + direct URL for large files
3. **For large videos:** Get JSON links, download from `googlevideo.com` directly (faster, no proxy bottleneck)

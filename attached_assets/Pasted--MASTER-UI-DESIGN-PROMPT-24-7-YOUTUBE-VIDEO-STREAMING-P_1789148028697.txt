# MASTER UI DESIGN PROMPT — 24/7 YOUTUBE VIDEO STREAMING PLATFORM

Design and create a premium, production-ready, fully responsive website UI for a modern **24/7 YouTube video streaming / continuous broadcasting platform**.

The website should feel like a real premium SaaS/media-tech product designed by an expert product-design team — NOT like a generic AI-generated website.

Use the supplied reference images as the primary visual direction. If reference images are provided, preserve their visual language, composition style, illustration quality, spacing philosophy, and branding while creating a cohesive website.

IMPORTANT:

* Design ONLY the **Landing Page** and **Login / Access Page**.
* Do not create dashboard pages or unnecessary internal application screens.
* Make every section feel like part of the same professional product.
* Keep the design highly polished, minimal, editorial, modern and memorable.
* Make the entire experience mobile-first and responsive.

---

# 1. BRAND / VISUAL DIRECTION

Create two connected visual identities:

## LOGIN / ACCESS PAGE

Use a sophisticated LIGHT theme.

Background:

* Soft mint/sage green
* Approximately `#F0F4EE`
* Very subtle tonal variations are acceptable

Primary accent:

* Deep forest green
* Orange used selectively for small highlights/details

Typography:

* Premium editorial serif for the major emotional headline
* Use italic styling selectively
* Headline should have a sophisticated magazine/editorial feeling
* Supporting text should use a clean modern sans-serif

Overall feeling:

* Premium
* Calm
* Trustworthy
* Private
* Human
* Editorial
* Minimal

Example headline treatment:

"Good to see
**you**"

Make the emphasized word visually distinctive using italic serif typography.

---

# 2. MAIN LANDING PAGE

Use a DARK cinematic theme.

Background:

* Deep black / near-black
* Approximately `#0A0F0A`

Primary accent:

* Neon/lime green
* Approximately `#C8F052`

Supporting colors:

* Soft off-white
* Muted gray-green
* Very subtle darker green surfaces

The lime green should provide strong contrast without making the interface look overly neon.

Overall feeling:

* Premium broadcast technology
* Modern media infrastructure
* Creative
* Minimal
* Confident
* Technical but approachable

---

# 3. NAVIGATION

Create a clean premium navigation bar.

LEFT:

* Brand logo
* Use the provided logo/reference asset if supplied
* Do not create a random unrelated logo

CENTER:

* Capabilities
* Use cases
* Pricing

RIGHT:

* "Access workspace" CTA
* Pill-shaped button
* Lime/green accent
* Clear hover state

Navigation should remain elegant and lightweight.

Desktop:

* Horizontal navigation

Tablet:

* Slightly compressed navigation

Mobile:

* Logo + compact menu button
* CTA should remain accessible without overcrowding

Add subtle sticky/floating navigation behavior if appropriate.

---

# 4. HERO SECTION

Create a highly impactful hero section.

Main headline should communicate effortless continuous broadcasting.

Use bold modern sans-serif typography.

Visual hierarchy should feel similar to premium editorial technology websites.

Suggested headline direction:

"Make the **signal feel**"

Use large typography with selective lime-green emphasis.

Supporting copy should communicate that users can continuously stream videos to YouTube with minimal effort.

Primary CTA:

* Strong lime-green pill button
* Example: "Start streaming"

Secondary CTA:

* Ghost/outline button
* Example: "See how it works"

Do not overcrowd the hero.

---

# 10. CARD SYSTEM

Cards across the dark landing page should follow one consistent design system.

Use:

* Near-black surfaces
* Very subtle green tint
* 1px green/olive borders
* Soft shadows
* Minimal glow
* Rounded but not excessively rounded corners

Avoid:

* Huge gradients everywhere
* Excessive glassmorphism
* Excessive blur
* Overly bright neon
* Generic AI SaaS cards

Cards should feel tactile and premium.

---

# 11. TYPOGRAPHY

Use a strong typography system.

Landing page:

* Modern bold sans-serif for headlines
* Clean sans-serif for body text
* Monospace/small uppercase labels for metadata

Login page:

* Editorial serif headline
* Italic emphasis
* Modern sans-serif body/form text

Create strong hierarchy between:

* Hero headline
* Section headings
* Card titles
* Labels
* Supporting copy

Typography must remain highly readable on mobile.

---

# 13. LOGIN PAGE RESPONSIVE BEHAVIOR

Desktop:

* Two-column composition
* Large editorial typography
* Floating access card

Tablet:

* Reduced spacing
* Balanced two-column layout

Mobile:

* Single-column layout
* Intro content at top
* Access card below
* Trust badges remain visible
* No horizontal overflow
* Large tap-friendly controls
* Minimum comfortable touch targets
* Typography automatically scales

The login experience must feel excellent on a small phone screen.

---

# 14. DARK / LIGHT MODE

Support both:

LIGHT MODE:

* Login/access experience
* Sage/mint background
* Forest green
* Orange accents
* Editorial typography

DARK MODE:

* Main landing page
* Near-black background
* Lime green
* Off-white typography

# 16. MICRO-INTERACTIONS

* Button hover

* Navigation transitions

* Premium

Respect reduced-motion accessibility preferences.

---

# 17. RESPONSIVE DESIGN

The website MUST be fully responsive.

Optimize specifically for:

* Large desktop
* Laptop
* Tablet
* iPhone-sized mobile screens
* Android mobile screens

Requirements:

* No horizontal scrolling
* No clipped text
* No overlapping elements
* Buttons remain easily tappable
* Images scale correctly
* Cards stack intelligently
* Navigation adapts properly
* Hero layout changes naturally
* Typography scales fluidly

Design mobile layouts intentionally rather than simply shrinking desktop layouts.

---

# 18. IMAGE / ASSET RULE

If the user provides images or reference screenshots:

USE THOSE PROVIDED IMAGES/ASSETS WHERE APPROPRIATE.

Do not replace supplied brand visuals with random stock imagery.

If an additional image/illustration is required:

* Generate it in the same visual language
* Maintain the same color palette
* Maintain consistent character/illustration style
* Maintain consistent lighting
* Maintain consistent proportions

Every visual should look as though it belongs to the same website.
